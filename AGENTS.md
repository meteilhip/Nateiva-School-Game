# Mandatory Pre-Implementation Rules

0. **Dedicated Host for Bilingual Kids Educational Game:**
   This workspace (`bold-nobel` / `nateiva-school-game`) is the **designated, sole host for all conversations, planning, curriculum design, and code implementation of the Bilingual Kids Educational Game** (*Nateiva School Game* / *EduKids*).
   All discussions regarding French/English bilingual education, learning activities, interactive simulations, and kids arcade gameplay strictly belong here. External creator platform projects (e.g. *ORRA*) are housed separately in their own repositories.

1. **Read [SchoolGameSoul.md](./SchoolGameSoul.md) FIRST:**
   Before planning, writing, modifying, or deploying any code in **Nateiva School Game**, you MUST read `SchoolGameSoul.md` and follow all architectural, pedagogical, UI, GitHub (`https://github.com/meteilhip/Nateiva-School-Game`), and Vercel (`https://vercel.com/nateiva-s-projects/nateiva-school-game`) rules defined within it.

2. **Expo Versioned Docs:**
   Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any Expo/React Native code.

3. **Always Track Version:**
   Every change must increment and document the semantic version in `package.json` (current: `v1.0.2`).
